# Zenodo drug feature files

The precomputed ViroBind drug feature files are publicly available through Zenodo.

- Record: [https://zenodo.org/records/22169453](https://zenodo.org/records/22169453)
- DOI: [10.5281/zenodo.22169453](https://doi.org/10.5281/zenodo.22169453)
- File: `drug_fea.zip`

Download and extract `drug_fea.zip`, then configure the training or prediction
commands to use the extracted drug feature files.

This record is cited here as the source of the drug feature files.
